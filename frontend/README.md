# 마음, 쉼 — 전체 프론트 시안

React 18로 만든 정적 프론트. Mercury를 참고한 흰색·쿨 그레이·퍼플 블루 배색과 둥근 카드 UI를 적용했다.

## 구현 범위

보고서의 개발 내용에 명시된 사용자 기능만 포함한다.

- 회원가입, 로그인, 로그아웃 화면과 로컬 체험 계정
- 고민 카테고리, 익명 게시글 작성·목록·상세·수정·삭제
- 익명 댓글 작성·조회·수정·삭제 및 본인 댓글 구분
- 계정별 공감 등록·취소와 중복 공감 방지
- AI 상담 대화, 답변 대기 상태, 상담 종료 (예시 답변)
- 본인의 상담 기록 저장·목록·대화 조회
- 내 활동의 본인 게시글·상담 목록
- 게시글 신고 접수·완료 및 관리자 신고 목록·상세·상태 변경
- 게시글 내용을 전달하여 비공개 AI 상담 시작

데이터는 localStorage, 로그인 상태는 sessionStorage를 사용한다. 실제 회원 인증, 서버 권한 검증, Spring Boot, MariaDB, Gemini API는 연결하지 않았다. 공개 링크를 통해 각자 이용할 수 있지만 서로 다른 브라우저의 데이터는 공유되지 않는다. 프론트의 권한 구분은 시연용으로 실제 보안 경계가 아니다. 실제 계정 비밀번호·민감한 고민은 입력하지 않는다.

예시 계정: `yejun`, `yechan`, `admin` / 예시 비밀번호: `maeum123!`. 로그인 화면에서 계정을 선택하면 입력값이 채워진다. 비밀번호 원문은 브라우저 저장소에 보관하지 않으며 체험용 로컬 해시만 사용한다.

## 실행

```sh
npm install
npm test
npm run build
npm run dev
```

로컬 주소: http://127.0.0.1:4178

`dist/index.html`은 배포 진입점이며 `dist/maeum.html`은 CSS와 React 번들을 포함한 단일 HTML이다. 웹 폰트가 없으면 시스템 한글 폰트로 표시된다. 해시 경로를 사용하므로 정적 호스팅에서도 새로고침할 수 있다.

## 나중에 연결할 백엔드

`src/model.js`의 로컬 작업을 API 호출로 교체한다. 작성자는 서버 인증 정보로 설정하고 소유권과 중복 공감은 서버·DB에서 다시 검증해야 한다. AI 메시지는 서버에서 Gemini를 호출하고 상담 기록도 본인 권한 검사 후 저장·조회해야 한다.
