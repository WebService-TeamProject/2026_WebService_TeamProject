# 마음, 쉼 — 전체 프론트 시안

React 18로 만든 정적 프론트. Mercury를 참고한 흰색·쿨 그레이·퍼플 블루 배색과 둥근 카드 UI를 적용했다.

## 구현 범위

보고서의 개발 내용에 명시된 사용자 기능만 포함한다.

- 회원가입, 로그인, 로그아웃 화면과 로컬 체험 계정
- 고민 카테고리, 익명 게시글 작성·목록·상세·수정·삭제
- 익명 댓글 작성·조회·수정·삭제 및 본인 댓글 구분
- 계정별 공감 등록·취소와 중복 공감 방지
- AI 상담 대화, 답변 대기 상태, 상담 종료 (예시 답변)
- 본인의 상담 기록 저장·목록·대화 조회
- 내 활동의 본인 게시글·상담 목록
- 게시글 신고 접수·완료 및 관리자 신고 목록·상세·상태 변경
- 게시글 내용을 전달하여 비공개 AI 상담 시작

정적 시연 화면은 localStorage와 sessionStorage로 동작한다. 공유 게시판 모드에서는 서버 계정으로 로그인하고 게시글을 Spring Boot API를 통해 MariaDB에 저장한다. 댓글, 공감, 신고, 상담 기록은 각 브라우저의 localStorage에 저장한다.

시연 모드 예시 계정: `yejun`, `yechan`, `admin` / 예시 비밀번호: `maeum123!`. 로그인 화면에서 계정을 선택하면 입력값이 채워진다. 비밀번호 원문은 브라우저 저장소에 보관하지 않으며 체험용 로컬 해시만 사용한다.

## 실행

```sh
npm install
npm test
npm run build
npm run dev
```

로컬 `http://127.0.0.1:4178`에서 공유 게시판을 연다. 실행 중인 백엔드의 기본 포트는 `8083`이며, 실행 방법은 [프로젝트 README](../README.md)를 참고한다. 시연 모드는 `http://127.0.0.1:4178/?demo`에서 연다.

`dist/index.html`은 배포 진입점이며 `dist/maeum.html`은 CSS와 React 번들을 포함한 단일 HTML이다. 웹 폰트가 없으면 시스템 한글 폰트로 표시된다. 해시 경로를 사용하므로 정적 호스팅에서도 새로고침할 수 있다.

공유 게시판의 로그인 인증 정보는 페이지 메모리에만 보관한다. 새로고침하면 다시 로그인한다.
