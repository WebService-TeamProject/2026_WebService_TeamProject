# 마음, 쉼 프론트엔드

React 18로 만든 화면입니다. [프로젝트 README](../README.md)에 따라 실행하면 게시글을 학교 MariaDB에 저장하고 조회할 수 있습니다.

- [시연 화면](http://127.0.0.1:4178/?demo)은 예시 데이터로 동작합니다. 로그인 화면에서 예시 계정 버튼을 누르면 입력값이 채워집니다.
- 댓글, 공감, 신고, 상담 기록은 브라우저에 저장되며 상담 답변은 예시입니다.
- 빌드 결과는 `dist/index.html`에 있고, 단일 HTML 시연 파일은 `dist/maeum.html`입니다.
